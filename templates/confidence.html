How to Save Confidence PicksPlayer instructions
  1. Pick any upcoming game you are ready to play; you do not need to finish the entire week at once.
  2. Give each saved pick a unique Confidence Value. A value already used on another saved game cannot be reused.
  3. Click Save Picks. Return later to finish or change games that have not kicked off.
  4. At each game's scheduled kickoff, that game locks and every player's saved pick for that game becomes visible.
  5. A missed game cannot be backfilled after kickoff. Enter the final-game tiebreaker before that final game begins.
